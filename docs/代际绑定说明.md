# 温谱导出代际绑定说明

记录日期：2026-11-22
记录人：班组（冷链温谱管道维护组）
效力：当日拍板，当日不再改口；后续变更须另起说明并注明取代本说明。

## 一、背景缺陷

温谱导出接口未绑定当前封批代：导出请求只带 `batch_id`，服务端不校验调用方
声明的封批代，运维可拉出上一代曲线冒充当代。血缘/互证页仅按条数声称一致，
对账实际挂在旧代上，形成“页面声称一致、对账挂旧代”的混轨。

## 二、拍板路径：甲路径（唯一口径，禁止与乙路径混用）

甲路径硬规则：

1. 温谱导出请求必须显式携带当前封批代 `generation`。
2. 服务端以 `temp_batches.generation`（当前封批代）并与最新
   `seal_snapshots.batch_generation` 双重比对：
   - 比对失败（请求代落后于当前代、超前于当前代、无封批快照）一律拒绝；
   - 拒绝时温谱正式表 `spectrum_exports` 零增（不插任何行，也不写影子行）。
3. 校验通过才允许写正式温谱行，正式行落绑定代列 `generation`，
   导出号仍为 `SP-{batch_code}-G{generation}`，同代重复导出继续拒绝。
4. 同批次并发导出须抢批次锁 `batch:{batch_id}`（与封批、游标同锁命名空间）：
   后到争用只写 `contention_log` 痕，不产生任何温谱文件/正式行。

乙路径（影子温谱文件 + 待代齐晋升合并）**明确不采用**：

- 不建影子表、不建影子状态、不建晋升/合并接口；
- 任何“先落影子、待代齐晋升”的写法均视为混轨，按代际偏航拒写。

折中写法不要。混轨会让旧代曲线混入当代批次。

## 三、五页同态口径

温谱页、封批页、批次页、血缘页、对账页五页展示须同态，统一口径：

- 批次当前代 = `temp_batches.generation`，展示为 `G{代}`；
- 封批快照代 = `seal_snapshots.batch_generation`；
- 温谱导出代 = `spectrum_exports.generation`（与导出号 `G{代}` 一致）；
- 对账互证须逐行核对导出代 == 当前封批代，存在错代正式行即
  `spectrum_matches_seal=false`，不得再用条数凑一致。

## 四、不变量（验收断言来源）

- I1：错代导出请求返回 409 且 `spectrum_exports` 正式行零增。
- I2：正式温谱册只允许出现当前封批代的正式行；不存在“影子/待晋升”行，
  未晋升影子不得出现在正式册（本系统不产生影子）。
- I3：同批并发双请求至多一个成功者、至多一份正式行，败者仅留争用痕。
- I4：五页对同一批次展示的导出代一致，且等于当前封批代。

## 五、偏航记录规则

实现与本说明任何一条偏离，须在本文件“代际偏航记录”节登记偏航原因与影响，
未登记的偏航代码一律拒写、拒合入。

## 代际偏航记录

无。本次实现严格按甲路径落地，未采用乙路径任何机制，无折中写法。
